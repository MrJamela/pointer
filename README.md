# PnP - Pointer and Pings! (Foundry v14)

Show a pointer that follows your mouse, and ping any spot on the map, for every player. Pointers and pings are
customisable per player. The GM can also ping and move every player's view to that spot.

This is a copy of [PnP - Pointer and Pings](https://github.com/p4535992/foundryvtt-pointer) (by Moerill, farling42,
p4535992, samulopez and Shr1mps) with fixes for Foundry VTT v14. See [CHANGELOG.md](CHANGELOG.md) for what changed.

## Install

In Foundry: **Add-on Modules → Install Module**, paste this into **Manifest URL**, then **Install**:

```
https://github.com/MrJamela/foundryvtt-pointer/releases/latest/download/module.json
```

It replaces the original module (same id, `pointer`). No other modules are needed.

## Use (default controls)

- **Hold X**: show your pointer; it follows your mouse on the map.
- **Hold X + left click**: ping that spot. Everyone sees it.
- **Hold X + right click** (GM only): ping and move every player's view to that spot.

Change the keys, and pick or design your pointer and ping, in **Game Settings → Configure Settings → PnP - Pointer and
Pings! → Settings and Design Studio**. A GM can apply their own choice to every player from the same window.
